## 中文

### 1. 本资料包的范围

本包是链接、元数据、公开 Prompt 引文和原创中文整理的资料集合。为保证 README 能直接显示，维护者把各案例演示制作成 GIF 预览镜像，托管在维护者自有存储；X 上的 MP4 被转为低码率 GIF 预览。镜像文件**不提交到 Git 历史**，每条均保留作者署名、原帖与原始文件链接。权利人要求移除时，删除对应镜像并改回外链。

本包未附加 MIT、CC0、CC BY 等统一素材许可证。将来若添加仓库代码许可证，该许可证只覆盖明确列出的代码与原创整理文字，不自动覆盖第三方作品、角色、Logo、输入照片、原始 Prompt 或外链页面。

### 2. 公开可播放不等于允许复制或商用

以下来源尤其需要单独判断：

- OpenAI 公告中的 OpenArt 合作作品
- Town 的 Monty 角色
- 用户的宠物、原创画稿与个人肖像
- Revor AI Logo、产品包装和已有品牌资产
- 蓝色大肥鱼等已有角色/IP
- Felo 或媒体二次转换、转存的 GIF
- X、Hacker News、个人网站上的用户作品

**"官方展示""作者公开发帖""链接返回 200"都不是复制、再分发或商业使用许可。**

### 3. 默认媒体策略

- 保存 `canonical_post_url`、`primary_url`、`demo_url` 和 `accessed_at`
- 未获许可时采用链接式索引；不将外链媒体提交到 Git 历史
- 不因原链接失效而自动将第三方素材复制到新图床
- 若获得镜像授权，在对应案例 `rights` 中记录许可范围、日期、凭证链接，再增加 `mirror_url`
- 展示时保留作者、原始来源和"官方/合作方/作者实测/媒体实测/二次收录"的区别
- 不为吸引眼球而隐去作品缺陷、Prompt 未公开或作者待溯源等事实

### 4. Prompt 的引用

完整 Prompt 按研究引用目的保留原文，并附来源；这不代表 Prompt 本身采用本包许可证。不要把整理者中文摘要写进 `prompt.text`。若权利人提出合理异议，应复核引用必要性、范围与展示方式。

### 5. 商业使用前的检查

- 确认输出及输入素材的使用条款与适用法律
- 检查角色、商标、包装、字体和肖像权
- 逐帧检查文字、产品边缘、Logo 和意外内容
- 棋局、Dashboard、教学信息等内容必须另行事实核验
- 透明 GIF 检查白边、锯齿和一位透明限制
- 单次成功案例不能当作输出稳定性保证

### 6. 更正与下架

作者或权利人可要求更正署名、补充原帖、移除镜像或调整引用。处理请求时保留必要的元数据修订记录，不静默篡改来源历史。

请通过 GitHub Issues 或 Pull Request 提交更正或下架请求。

## English

### 1. Scope of This Package

This package is a collection of links, metadata, public prompt quotations, and original Chinese editorial content. So the README can display demos inline, the maintainer hosts GIF preview mirrors on the maintainer's own storage; X MP4s are converted to low-bitrate GIF previews. Mirror files are **not committed to Git history**, and every case keeps attribution plus original post and original file links. On a rights holder's request the mirror is removed and the entry reverts to the external link.

This package does not attach a unified asset license such as MIT, CC0, or CC BY. If a repository code license is added later, it only covers explicitly listed code and original editorial text, not third-party works, characters, logos, input photos, original prompts, or externally linked pages.

### 2. Publicly Playable ≠ Permission to Copy or Commercialize

The following sources especially require individual assessment:

- OpenArt collaborative works in OpenAI announcements
- Town's Monty character
- Users' pets, original sketches, and personal portraits
- Revor AI Logo, product packaging, and existing brand assets
- Existing characters/IPs
- GIFs converted or rehosted by Felo or media outlets
- User works on X, Hacker News, or personal websites

**"Official showcase," "author publicly posted," and "link returns 200" are NOT permissions to copy, redistribute, or use commercially.**

### 3. Default Media Policy

- Save `canonical_post_url`, `primary_url`, `demo_url`, and `accessed_at`
- Use link-based indexing when permission is not obtained; do not commit external media to Git history
- Do not automatically copy third-party assets to new image hosts when original links expire
- If mirroring permission is obtained, record permission scope, date, and credential link in the case's `rights`, then add `mirror_url`
- When displaying, preserve distinctions between author, original source, and "official/partner/author test/media test/secondary collection"
- Do not hide work defects, unpublished prompts, or pending author attribution for attention

### 4. Prompt Quotation

Complete prompts are preserved verbatim for research citation purposes, with sources attached; this does not mean the prompt itself is under this package's license. Do not put curator's Chinese summaries into `prompt.text`. If rights holders raise reasonable objections, review the necessity, scope, and display method of quotation.

### 5. Checks Before Commercial Use

- Confirm usage terms and applicable laws for outputs and input materials
- Check character, trademark, packaging, font, and portrait rights
- Check text, product edges, logos, and unexpected content frame by frame
- Chess games, dashboards, educational information, etc. must be fact-checked separately
- Transparent GIFs should be checked for white edges, aliasing, and 1-bit transparency limitations
- A single successful case cannot be used as a guarantee of output stability

### 6. Corrections and Takedowns

Authors or rights holders may request attribution corrections, original post additions, mirror removal, or quotation adjustments. When processing requests, preserve necessary metadata revision records and do not silently alter source history.

Please submit correction or takedown requests via GitHub Issues or Pull Requests.
