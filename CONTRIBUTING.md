# Contributing / 贡献指南

[English](#english) · [中文](#中文)

---

## English

Thanks for helping grow this prompts guide! The bar is **verifiable**, not just "more".

### How to contribute

1. **Suggest a case** — open an [Issue](https://github.com/sparkle027/awesome-gpt-image-2.6-gif/issues/new) with:
   - a link to the **original post** (author's own post / gallery / official page — not a repost aggregator)
   - the author's name and profile link
   - the **full prompt exactly as the author published it** (if public)
   - a link to the GIF / video demo
2. **Fix something** — wrong author, dead link, mismatched preview, typo in a translation: open an Issue or a PR on the relevant `README` / `translations/*.md`.
3. **Improve a translation** — PRs to `translations/README.<lang>.md` are welcome. Only the page text is translated; prompts stay in their original language.

### Rules

- **Never invent or reverse-engineer a prompt.** If the author didn't publish it, the case goes under *Showcase only*.
- Keep prompts **verbatim** — original language, casing, punctuation, even typos.
- Credit the original creator; one case = one work, even if reposted many times.
- Product slogans or the author's commentary are not prompts.
- Don't commit GIF / MP4 files to the repo.
- Removal requests from rights holders are honored — see [RIGHTS.md](RIGHTS.md).

## 中文

感谢参与完善这份 Prompts 指南！收录标准是**可核实**，而不只是数量。

### 怎么贡献

1. **推荐案例**：提 [Issue](https://github.com/sparkle027/awesome-gpt-image-2.6-gif/issues/new)，附上：
   - **原帖链接**（作者本人帖子 / 图集 / 官方页面，不要搬运聚合页）
   - 作者名称与主页
   - 作者公开的**完整 Prompt 原文**（如有）
   - GIF / 视频演示链接
2. **纠错**：作者写错、链接失效、预览图与描述不符、翻译错别字，直接提 Issue 或对 `README` / `translations/*.md` 提 PR。
3. **改进翻译**：欢迎对 `translations/README.<语言>.md` 提 PR。只翻译页面文字，Prompt 保持原文。

### 规则

- **不编造、不反推 Prompt。** 作者未公开的，只放在「无公开 Prompt」区。
- Prompt **逐字保留**：原语言、大小写、标点，连拼写错误也不改。
- 署名原作者；同一作品被多次转载只算一条。
- 产品宣传语、作者感想不算 Prompt。
- 不要把 GIF / MP4 文件提交进仓库。
- 权利人要求移除会尽快处理，见 [RIGHTS.md](RIGHTS.md)。
